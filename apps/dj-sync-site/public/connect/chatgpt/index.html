Connect ChatGPT

Add DJ Sync to ChatGPT once on the web. It then works in the ChatGPT app on your phone as well.

  1. Copy your private link from DJ Sync

    Click the DJ Sync icon in your menu bar, go to Assistants, click Connect ChatGPT and then Copy. It looks like https://djsync.jeffrey.build/…/…/mcp.

    Treat this link like a password. Anyone with it can send requests to your Mac. If it ever leaks, use Rotate in the same place: the old link stops working at once.

  2. Add it to ChatGPT

    On a computer, open chatgpt.com and go to Plugins. Click Add, then Create custom MCP server, and fill in:

    • Name: DJ Sync
    • MCP server URL: paste your link
    • Authentication: No authentication (the link itself is the key)

    Save it. ChatGPT may warn that the server isn’t verified by OpenAI. That’s expected for independent apps like DJ Sync.

    ChatGPT’s menus move around. If you can’t find Plugins, look for adding a connector or a custom MCP server in Settings. If your plan doesn’t offer custom MCP servers, Claude’s free plan allows one custom connector.

  3. Ask

    Start a chat and mention DJ Sync (or pick it from the tools menu). ChatGPT asks you to confirm before it changes anything. Try:

    • “Download https://open.spotify.com/track/… and add it to a playlist called Friday Warm-up.”
    • “Search my library for amapiano between 110 and 115 BPM and make a playlist of the results.”
    • “Rename Friday Warm-up to Friday Opening.”
    • “What happened to my last download?”

    The DJ Sync menu shows Connected once ChatGPT has used your link.
