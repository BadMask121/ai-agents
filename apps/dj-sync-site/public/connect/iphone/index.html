Connect iPhone

Add DJ Sync to your iPhone’s Share menu. Share a song from Spotify or YouTube, pick a playlist, done. Free, no account, about five minutes to set up.

This uses Apple’s Shortcuts app, so it’s for iPhone and iPad. On Android, use Telegram.

  1. Get your API address and key

    Click the DJ Sync icon in your menu bar, go to Assistants and click Connect iPhone. DJ Sync shows two things, each with a Copy button:

    • API URL: https://djsync.jeffrey.build/api/downloads
    • Key: a long private code.

    To get the key onto your phone, copy it on your Mac and paste it on your iPhone (this works when both use the same Apple ID with Handoff on), or AirDrop it to yourself.

    Treat the key like a password. Anyone with it can send downloads to your Mac. If it leaks, use Rotate in the same place and update the key in your Shortcut.

  2. Build the Shortcut

    Open the Shortcuts app, tap +, name it DJ Sync, and add these actions in order. Wherever it says Bearer YOUR-KEY, type the word Bearer, a space, then paste your key.

    1. Receive input from the Share Sheet. Tap the shortcut’s ⓘ, turn on Show in Share Sheet, and set the input it receives to URLs. The first action then reads Receive URLs from Share Sheet.
    2. Get Contents of URL (your playlists): URL https://djsync.jeffrey.build/api/playlists, method GET. Under Headers, add Authorization with the value Bearer YOUR-KEY.
    3. Get Dictionary Value: get the Value for playlists in Contents of URL. Then add a second Get Dictionary Value: the Value for path in Dictionary Value. This gives the list of playlist names, like GQOM/Gqom.
    4. Choose from List: choose from the second Dictionary Value, with the prompt Add to which playlist?
    5. Get Contents of URL (send it): URL https://djsync.jeffrey.build/api/downloads, method POST, the same Authorization header, and Request Body: JSON with two fields:
      • url (Text) = Shortcut Input
      • playlist_name (Text) = Chosen Item
    6. Show Notification: Sent to DJ Sync.
    Your playlists come back with DJ Sync’s own folder first, then A to Z. Sending the playlist’s full name, Folder/Name, makes DJ Sync pick exactly that one, even if two playlists share a name.

  3. Share a song

    In Spotify or YouTube, tap Share (you may need More), choose DJ Sync, then pick a playlist. The track downloads on your Mac into that Rekordbox playlist. If your Mac is asleep or offline, it waits and runs as soon as it’s back. The DJ Sync menu shows it under Recent.
